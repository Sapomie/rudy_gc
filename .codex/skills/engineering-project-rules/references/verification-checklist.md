# 验证与收尾清单

## 通用验证

- Go 项目：运行 `gofmt` 和相关包 `go test`。
- 前端模板：运行项目可用的模板检查、静态检查或至少做 `git diff --check`。
- SQL 改动：执行 `EXPLAIN` 或给出等价索引命中分析。
- 缓存相关改动：确认写路径会失效缓存；直写后清理受影响缓存。
- 生成代码相关改动：确认生成文件、自定义文件和调用点一致。

## 检索自检

- 检索旧方法名、旧字段名、旧 URL、旧查询参数。
- 检索新增字段的所有写入口和读入口。
- 检索模板中是否残留手工拼接路径。
- 检索是否有未使用 helper、DTO、JS handler 或 CSS class。

## 运行收尾

- 如果启动本地服务、调试脚本或后台进程，验证结束后关闭。
- 如果占用了端口，确认端口释放。
- 如果修改了数据库但没有走正常写路径，清理相关缓存。
- 最终回复应说明已验证项、未验证项和剩余风险。
