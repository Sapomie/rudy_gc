# gc-web-next02 全页面导航统一改造计划

## 1. 计划目标

本计划用于统一 `v3/gc-web-next02` 全部页面的左侧导航栏和顶部导航栏。

导航结构以当前 Cards 页面使用的共享导航为基准，在其结构、尺寸、折叠方式和响应式行为上进行统一；导航视觉主题改为当前 `/sc-events` 使用的粉色体系。

最终目标：

- 全部 next02 页面使用同一套左侧导航栏。
- 全部 next02 页面使用同一套顶部导航栏。
- 导航结构、尺寸、活动状态和响应式行为保持一致。
- 导航颜色、边框、阴影和交互反馈统一为粉色主题。
- 清除不同路由对导航尺寸和主题的独立覆盖。
- 不改变各页面主体内容、业务字段、按钮、API 和业务行为。

## 2. 适用范围

### 2.1 代码范围

- `v3/gc-web-next02/src/layouts/AppLayout.vue`
- `v3/gc-web-next02/src/styles/index.css`
- `v3/gc-web-next02/src/data/navigation.ts` 只用于核对导航数据，默认不修改内容。
- `v3/docs/standard/gc_web_next02_frontend_style_standard.md`

### 2.2 页面范围

所有由 next02 Router 加载并使用 `AppLayout.vue` 的页面都属于本计划范围，包括：

- 首页
- MovieCard 页面
- MovieAgg 页面
- List 页面
- SC 页面
- 抓取任务页面
- FetchSite 操作页面
- 色花堂 SH 页面
- Media 操作页面
- 左侧导航未直接展示的详情、兼容和内部路由
- NotFound 页面

### 2.3 版本边界

- 只修改 `v3/gc-web-next02`。
- 禁止修改其他 next 版本。
- 禁止把导航改造扩展到后端或其他项目。

## 6. 全局导航尺寸

以 Cards 当前导航尺寸为基准。

| 项目 | 规格 |
|---|---|
| 左侧导航宽度 | `220px` |
| 顶部导航高度 | `64px` |
| 品牌区宽度 | `220px` |
| 品牌区高度 | `64px` |
| 品牌标识 | `32px × 32px` |
| 侧栏分组标题最小高度 | `38px` |
| 侧栏链接最大高度 | `30px` |

禁止路由单独将侧栏改成 `240px`、顶栏改成 `51px` 或隐藏品牌与当前标题。

## 7. 左侧导航栏方案

### 7.1 外观

- 背景使用 `#4b2939 -> #351f2a` 的纵向渐变。
- 侧栏文字使用浅粉白色。
- 次要文字和数量胶囊使用低透明浅粉色。
- 分组之间保持 Cards 当前紧凑间距。
- 侧栏滚动条保持低干扰样式。

### 7.2 品牌区

- 保持品牌入口、品牌标识和品牌文字可见。
- 品牌区背景使用深粉棕渐变。
- 品牌标识使用主粉色到次强调粉的渐变。
- 品牌文字使用浅粉白色。
- hover 只增强粉色光泽，不移动品牌区。

### 7.3 分组标题

- 保持 Cards 当前左对齐结构。
- 分组标题默认使用浅粉灰文字。
- hover、focus 和展开状态使用低透明粉色背景。
- 当前分组使用更明显但克制的粉色背景。
- 分组左侧强调线使用 `#ef8fba`。
- 分组数量胶囊使用浅粉边框。

### 7.4 子链接

- 保持 Cards 当前缩进、行高和紧凑间距。
- 默认文字使用浅粉灰。
- hover 使用半透明粉色背景。
- 当前路由使用半透明主粉色背景、白色文字和左侧粉色强调线。
- hover、active 和 focus 不得改变链接尺寸。

### 7.5 展开与折叠

- 保留当前分组自动展开规则。
- 保留用户手动展开和折叠规则。
- 路由切换后继续恢复当前路由所属分组。
- 保留侧栏整体收起功能。
- 收起动画使用 Cards 当前 `220ms` 节奏。

## 8. 顶部导航栏方案

### 8.1 外观

- 顶栏使用白色到浅粉背景。
- 底部分隔线使用 `#eed5e1`。
- 阴影使用低透明粉色阴影。
- 保留背景模糊效果。
- 顶栏固定在页面顶部。

### 8.2 左侧区域

- 保留侧栏收起按钮。
- 保留当前页面标题。
- 全部页面必须显示当前页面标题。
- 菜单按钮使用浅粉背景、粉色边框和深粉图标。
- hover、focus 使用主粉色焦点反馈。

### 8.3 快捷导航分组

- 保持 Cards 当前横向分组结构。
- 分组容器使用浅粉背景和粉色细边框。
- 分组标签使用次要粉棕文字。
- 普通入口使用透明或白色背景和深粉文字。
- hover 使用 `#fff0f6`。
- 当前入口使用 `#d94f8a` 背景和白色文字。
- 当前入口阴影使用低透明粉色阴影。

### 8.4 空间不足处理

- 中等宽度下，快捷导航区域允许自身横向移动。
- 隐藏视觉滚动条，但保留滚动能力。
- 不得让整个页面产生横向滚动。
- 当前页面标题可以单行省略。

### 8.5 页面操作区

- 保留现有 `top-legacy-actions` 条件和按钮。
- 页面操作按钮统一使用粉色边框、浅粉背景和粉色 hover。
- 不新增无业务功能的操作按钮。

## 9. 页面入口行为

导航栏中所有进入页面的链接必须在当前窗口内通过前端路由跳转。

适用入口：

- 品牌首页入口
- 左侧导航入口
- 顶部快捷导航入口

品牌入口、左侧导航入口和顶部快捷导航入口统一保留 `RouterLink` 的 `to` 属性，不设置 `target="_blank"` 和 `rel="noopener noreferrer"`。

以下操作继续在当前窗口执行：

- 左侧分组展开与折叠
- 侧栏整体收起与展开
- 当前界面内的非导航按钮

## 10. AppLayout 改造

### 10.1 模板修改

在 `AppLayout.vue` 中：

- 品牌 `RouterLink` 移除新窗口属性。
- 左侧导航 `RouterLink` 移除新窗口属性。
- 顶部快捷导航 `RouterLink` 移除新窗口属性。
- 保留现有 `to`、活动状态、title 和 aria 属性。
- 保留分组按钮和菜单按钮的当前窗口行为。

### 10.2 脚本逻辑

保留：

- `routeClass`
- `isActive`
- `isTopLinkActive`
- `isGroupOpen`
- `isGroupActive`
- `toggleGroup`
- 路由切换后的分组状态更新

禁止因视觉改造重写导航业务逻辑。

## 11. 现有路由差异处理

当前 `index.css` 中存在大量路由级导航覆盖，包括：

- 品牌背景差异
- 品牌隐藏
- 当前标题隐藏
- 侧栏宽度差异
- 顶栏高度差异
- 侧栏起始位置差异
- 顶栏 padding 差异
- 主内容左边距差异
- 主内容顶部偏移差异
- 顶部导航分组颜色差异

### 11.1 处理原则

- 建立一个位于导航样式末尾的共享导航规格层。
- 共享规格必须覆盖全部 route class 的导航尺寸和主题差异。
- 页面主体专属样式继续保留。
- 不得用导航改造覆盖页面内容区颜色、表格或卡片样式。

### 11.2 必须统一的属性

全部路由统一：

- `--nav-side-width: 220px`
- `--nav-top-height: 64px`
- 品牌显示
- 品牌区尺寸
- 侧栏位置和宽度
- 顶栏尺寸和 padding
- 当前标题显示
- 快捷导航结构
- 主内容左边距
- 主内容顶部偏移
- 侧栏收起联动

### 11.3 禁止使用方式

- 禁止为每个路由复制一份相同导航 CSS。
- 禁止使用大量 `!important` 强制覆盖。
- 禁止删除页面主体需要的 route class。
- 禁止用全局颜色变量误伤页面主体主题。

导航颜色必须使用独立的 `--nav-*` 变量，避免改变页面内容区现有变量。

## 12. 建议导航变量

```css
--nav-side-width: 220px;
--nav-top-height: 64px;
--nav-primary: #d94f8a;
--nav-primary-dark: #9f2f63;
--nav-primary-soft: #fff0f6;
--nav-secondary: #ef8fba;
--nav-side-start: #4b2939;
--nav-side-end: #351f2a;
--nav-top-bg: #fffafd;
--nav-line: #eed5e1;
--nav-line-soft: #f1dce6;
--nav-text: #fff4f8;
--nav-muted: #8b6577;
```

## 13. 主内容联动

### 13.1 桌面端

- 主内容左边距统一为 `220px`。
- 主内容顶部偏移与 `64px` 顶栏匹配。
- 侧栏收起后主内容左边距恢复为 `0`。
- 顶栏左侧 padding 同步恢复到普通值。

### 13.2 页面自身布局

- 不改变各页面 PageShell 宽度。
- 不改变页面卡片、表格、海报和表单布局。
- 路由原有页面顶部隐藏规则只针对页面自身 heading，不得再隐藏全局导航标题。

## 14. 响应式规则

### 14.1 桌面端

- 左侧导航固定 `220px`。
- 顶栏固定 `64px`。
- 快捷导航横向排列。
- 主内容使用左侧和顶部偏移。

### 14.2 中等宽度

- 顶栏标题宽度允许收窄。
- 快捷导航区域独立横向移动。
- 页面整体不得横向滚动。
- 侧栏尺寸保持不变，直到移动端断点。

### 14.3 移动端

保留 Cards 当前移动端逻辑：

- 品牌区变为整行。
- 侧栏变为静态整行区域。
- 侧栏最大高度受控并允许内部滚动。
- 顶栏变成单列布局。
- 快捷导航占满宽度。
- 主内容取消左侧偏移。
- 主内容使用移动端顶部间距。
- 收起侧栏后隐藏侧栏内容。

## 15. 动画与可访问性

- 侧栏收起动画保持 `220ms`。
- hover 和 focus 动画控制在 `150ms` 至 `180ms`。
- focus 必须有清晰粉色轮廓。
- 当前路由必须保留 `aria-current="page"`。
- 分组按钮必须保留 `aria-expanded`。
- 菜单按钮必须保留 aria-label 和 aria-pressed。
- 必须提供 `prefers-reduced-motion: reduce` 覆盖导航位移和 hover 动画。

## 16. 文档同步

- `/sc-events` 粉色体系为默认导航主题。

- 禁止页面单独修改导航尺寸和主题。

- 特殊导航结构必须由用户明确提出。
