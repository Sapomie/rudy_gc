# gc-web-next02 `/triggers/seeds` 重写计划

## 1. 文档目标

本计划用于重写 `v3/gc-web-next02` 的 `/triggers/seeds` 页面，使其在保持现有任务功能、参数、接口和运行逻辑不变的前提下，对齐以下两个现有页面：

- `/sc-events`：作为页面主题、整体几何、紧凑 Hero、面板边界、控件状态和动画基准。
- `/w-media-agg/birth`：作为聚合信息组织、面板工具栏、分段控件、指标单元和高密度信息展示基准。

本次重写只面向桌面端，不新增移动端布局，不修改后端，不改变任务执行语义。

## 2. 强制依据

实施前必须完整阅读并遵循：

- `v3/docs/standard/gc_web_next02_frontend_style_standard.md`
- 当前 `/sc-events` 的真实 DOM、最终计算样式和浏览器渲染结果
- 当前 `/w-media-agg/birth` 的真实 DOM、最终计算样式和浏览器渲染结果
- 当前 `/triggers/seeds` 的任务按钮、表单字段、任务控制、运行概览、事件流和轮询逻辑

视觉对齐不能改变以下内容：

- API 路径
- 任务类型值
- 表单字段名
- 默认值
- 请求参数
- 任务启动与控制方法
- 任务状态判断
- 轮询频率与轮询生命周期
- 事件数据处理方式
- 原始 JSON 显示逻辑

## 4. 当前页面问题

当前 `/triggers/seeds` 已有独立的 Seeds 视觉层，但与 next02 当前标准存在明显分离：

- 页面使用蓝色、青色和琥珀色主题变量，未采用 `/sc-events` 粉色主题。
- 当前路由单独覆盖左侧导航为 `240px`、顶部导航为 `51px`，与统一的 `220px/64px` 导航规格冲突。
- Hero 使用透明无边框结构，且底部间距较大，未对齐 `/sc-events` 的紧凑单行 Hero。
- 任务面板、运行概览和事件面板使用独立的冷色面板体系。
- 任务类型按钮呈大尺寸三列按钮阵列，信息密度低于 `/w-media-agg/birth` 的分段控件。
- 运行阶段指标以大量通用 overview 卡片铺开，阶段关系和层级不够集中。
- 事件流区域延续独立蓝色终端风格，与页面整体主题割裂。
- 面板 hover 存在位移，容易造成页面几何轻微变化。
- 当前 CSS 同时受到共享 Trigger 样式和 Seeds 路由专属样式影响，重写时需要清理冲突层，避免继续追加覆盖。

## 5. 双基准职责

### 5.1 `/sc-events` 负责的基准

以下规格严格以 `/sc-events` 为准：

- 页面背景和主题色
- 页面根容器内边距
- Hero 与主面板左右边界
- Hero 高度、内边距、边框、圆角和阴影
- 标识、标题、说明和操作区的单行排列
- 面板边框、圆角、背景和阴影
- 粉色强调线
- 输入框、按钮、状态胶囊和焦点环
- hover、active、focus-visible、disabled 状态
- 页面进入动画和 reduced-motion 处理
- 跨页面入口的新窗口行为
- 不出现横向滚动条

主题变量固定使用：

| 用途 | 色值 |
|---|---|
| 主粉色 | `#d94f8a` |
| 深粉色 | `#9f2f63` |
| 主文字 | `#4b2939` |
| 次要文字 | `#8b6577` |
| 主浅粉 | `#fff0f6` |
| 次浅粉 | `#fff5fa` |
| 面板标题背景 | `#fcecf4` |
| hover 背景 | `#fde8f2` |
| 主边框 | `#eed5e1` |
| 次边框 | `#f1dce6` |

### 5.2 `/w-media-agg/birth` 负责的基准

以下信息组织方式参考 `/w-media-agg/birth`：

- 面板顶部紧凑工具栏
- 工具栏左侧标题和粉色竖向强调线
- 工具栏右侧分段控件或状态控件
- 高密度指标单元
- 主指标和辅助说明的视觉层级
- 大量指标在固定面板内的规则化排列
- 内容分组之间使用细分隔线
- 面板内信息保持紧凑且可快速扫描

只复用信息组织方式，不复制 `/w-media-agg/birth` 的业务名称、时间桶数据或电影卡片结构。

## 6. 目标页面结构

目标页面由一个紧凑 Hero 和一个主工作区组成：

```text
PageShell
└── Seeds 页面根容器
    ├── 紧凑 Hero
    │   ├── Seeds Console 标识
    │   ├── 页面标题
    │   ├── 页面说明
    │   └── 跨页面入口
    └── Seeds 工作区
        ├── 左列
        │   ├── 任务控制面板
        │   └── 运行概览面板
        └── 右列
            └── 事件流面板
```

桌面端保留当前左侧控制、右侧事件流的工作关系。主工作区仍以两列呈现，但重新规划列宽和面板内部密度，避免为了视觉对齐改变操作顺序。

## 7. 紧凑 Hero 改造

### 7.1 内容

Hero 保留并重新排列：

- 标识：`SEEDS / TASK CONSOLE`
- 页面标题：使用接口返回的现有标题
- 页面说明：使用接口返回的现有说明
- 右侧入口：保留 `HeaderLinks` 以及当前补充的任务列表、SC 预览与提交入口

### 7.2 结构

- 标识、标题、说明和入口在桌面端尽量保持同一行。
- 删除 Hero 中重复的 KPI 指标；任务状态和当前任务类型放在工作面板内展示。
- Hero 左侧使用 `3px` 粉色渐变强调线。
- Hero 的页面边界、内边距和底部间距严格对齐 `/sc-events`。
- `PageShell` 自带的重复标题区域继续隐藏。

### 7.3 链接行为

所有进入其他页面的 Hero 链接必须设置：

```html
target="_blank"
rel="noopener noreferrer"
```

任务类型切换、表单输入和任务控制继续在当前页面中执行。

## 8. 任务控制面板

### 8.1 面板工具栏

任务控制面板采用 `/w-media-agg/birth` 的紧凑工具栏结构：

- 左侧显示 `Seeds Console` 和当前任务面板标题。
- 标题前使用粉色竖向强调线。
- 右侧显示当前任务状态胶囊：`Ready`、`Running`、`Paused` 或 `Done`。
- 工具栏与内容区之间使用 `1px #f1dce6` 分隔线。

### 8.2 任务类型

保留接口返回的全部 `TaskButtons` 和真实 `task_type` 值。

视觉改造为紧凑分段控件：

- 默认背景为白色或浅粉色。
- 默认文字使用次要文字色。
- hover 使用 `#fde8f2`。
- active 使用 `#d94f8a` 背景和白色文字。
- focus-visible 使用粉色焦点环。
- 按钮切换不得产生位移。
- 按钮宽度按真实标签内容和面板空间分配，禁止无依据固定成三等分大按钮。

### 8.3 动态字段

保留现有显示条件：

- `spider_seed_by_name` 显示 Seed 名称。
- `spider_refresh_oldest_detail` 显示刷新数量。
- 支持自动抓取外站的任务继续显示自动抓取选项。
- 当前页面现有的其他动态字段判断继续保留。

控件规格：

- 输入框和下拉框高度保持紧凑统一。
- 标签、说明、控件之间使用稳定的小间距。
- 输入框采用浅粉背景、粉色 focus 边框和焦点环。
- checkbox 区域改成紧凑选择行，不使用大块冷色悬浮卡片。
- 业务说明继续展示，不新增重复帮助文字。

### 8.4 操作区

保留按钮和原行为：

- 开始执行
- 暂停
- 继续
- 停止

操作区调整为面板底部紧凑操作栏：

- 高度、圆角和字号与 `/sc-events` 控件体系一致。
- 主操作使用主粉色。
- 暂停、继续、停止允许保留必要状态色，但不得发展成新的页面主题色。
- disabled 状态清晰且不响应 hover 位移。
- 不改变按钮启用条件和事件处理方法。

- 工具栏下方展示阶段指标。
- 进度条、状态文字和事件数量位于面板底部。

### 9.2 阶段指标

`seeds_stages` 当前包含的指标必须全部保留：

- 当前阶段
- 已运行时长
- 种子抓取进度
- 种子抓取正确/错误
- 详情抓取进度
- 详情抓取正确/错误
- 封面下载进度
- 封面下载正确/错误
- 标题翻译进度
- 标题翻译正确/错误
- JavBus 抓取进度
- JavBus 抓取正确/错误

- Sukebei 抓取正确/错误

1. 运行状态
2. 种子抓取
3. 详情抓取
4. 封面下载
5. 标题翻译

分组只改变视觉结构，不改变 `overviewItems` 的数据来源、字段含义和更新逻辑。

### 9.3 指标单元

- 单元使用白色背景、粉色细边框和小圆角。
- 标签使用 `#8b6577`。
- 数值使用 `#4b2939` 或 `#9f2f63`。
- 数字使用等宽数字特性。
- 正确/错误值保持在同一行。
- 指标单元不得通过 hover 位移。
- 指标数量较多时在面板内部规则化排列，不裁剪、不隐藏指标。

### 9.4 进度与状态

- 进度条主色改为粉色渐变。
- 保留当前进度值、状态文字和事件数量。
- `Live` 和事件数量使用紧凑胶囊。
- 保留当前动画语义，同时为 `prefers-reduced-motion` 关闭非必要流动动画。

### 11.1 全局边界

### 11.2 主工作区

- 左列容纳任务控制和运行概览。

- 桌面端空间不足时按 DOM 顺序换行，禁止产生横向滚动条。

## 13. 状态与动画

### 13.1 页面进入

- 页面根容器使用约 `280ms` 的淡入。
- Hero 和面板允许小幅上浮进入。
- 禁止强缩放和大距离位移。

### 13.2 交互状态

以下控件必须具备完整状态：

- 任务类型分段按钮
- 输入框
- checkbox
- 开始、暂停、继续和停止按钮
- Hero 跨页面入口
- 原始 JSON 开关

普通 hover 动画保持在 `140ms–180ms` 范围，且不得改变面板边界、控件尺寸或内容位置。

### 13.3 Reduced motion

在 `prefers-reduced-motion: reduce` 下关闭：

- 页面和面板进入位移
- 进度条非必要流动动画
- 非必要 hover 动画

保留状态变化本身，确保功能反馈仍然可辨识。
