# gc-web-next02 `/sc-events-cards` 粉色主题改造方案

## 1. 文档目的

本文档用于指导 `v3/gc-web-next02` 的 `/sc-events-cards` 页面改造，使其在视觉主题、页面密度、控制栏结构和交互反馈上与当前 `/sc-events` 页面保持一致，同时保留卡片视图适合浏览封面和事件摘要的特点。

默认样式规则以 `v3/docs/standard/gc_web_next02_frontend_style_standard.md` 为准；本文档只补充 `/sc-events-cards` 的页面级具体方案。

## 2. 改造目标

- 将 `/sc-events-cards` 改造成 `/sc-events` 的同主题卡片视图。
- 统一使用当前粉色主题、紧凑顶部、统计胶囊、分页和交互反馈。
- 保留现有事件卡片、封面、字段、排序、分页、详情入口和 API。
- 保持列表页适合比较数据、卡片页适合浏览封面的差异。
- 页面整体不得出现横向滚动。
- 页面入口链接必须在新窗口打开。

## 3. 修改范围

### 3.1 允许修改

- `v3/gc-web-next02/src/pages/ScEventsPage.vue`
- `v3/gc-web-next02/src/styles/index.css`
- 本改造需要同步记录时，可更新对应 next02 文档。

### 3.2 禁止修改

- 禁止修改其他 next 版本。
- 禁止修改 `/sc-events` 的业务字段和查询语义。
- 禁止修改后端接口、数据库结构和持久化逻辑。
- 禁止删除现有卡片字段、排序项、分页参数或详情入口。

## 4. 当前页面需要解决的问题

- 卡片页仍使用旧的顶部标题、摘要和排序布局，与当前 `/sc-events` 粉色主题不一致。
- 统计信息、排序和分页的视觉层级与列表页不统一。
- 卡片边框、背景、标签和 hover 反馈未使用当前粉色体系。
- 页面入口链接的新窗口行为需要统一。
- 卡片信息需要重新建立主次层级，避免标签堆叠和高度不一致。

## 5. 页面结构

改造后的页面模块顺序固定为：

1. 紧凑顶部区域
2. 卡片页控制栏
3. 卡片网格
4. 空状态

不得在上述结构之间新增重复统计卡、重复说明卡或装饰性大模块。

## 6. 公共主题作用域

### 6.1 类名规划

在页面根节点增加公共粉色主题类：

```text
next02-sc-pink-theme
```

列表页保留：

```text
next02-sc-events-rewrite
```

卡片页增加：

```text
next02-sc-event-cards-rewrite
```

### 6.2 作用域职责

`next02-sc-pink-theme` 负责：

- 页面背景
- 粉色主题变量
- 顶部面板
- 视图按钮
- 回填入口
- 统计胶囊
- 分页
- 公共链接状态
- 页面进入动画

`next02-sc-events-rewrite` 只负责列表布局和表格规则。

`next02-sc-event-cards-rewrite` 只负责控制栏、卡片网格、卡片内容和卡片响应式规则。

禁止用卡片页规则覆盖列表页表格尺寸和列宽。

## 7. 默认颜色

| 用途 | 色值 |
|---|---|
| 主粉色 | `#d94f8a` |
| 深粉文字与链接 | `#9f2f63` |
| 主文字 | `#4b2939` |
| 次要文字 | `#8b6577` |
| 主浅粉背景 | `#fff0f6` |
| 次浅粉背景 | `#fff5fa` |
| 卡片浅粉背景 | `#fffafd` |
| hover 背景 | `#fde8f2` |
| 主边框 | `#eed5e1` |
| 细分隔线 | `#f1dce6` |

## 8. 紧凑顶部区域

### 8.1 内容

左侧依次显示：

- `SC / EVENT STREAM`
- `SC Event Cards`
- 卡片视图简短说明

右侧显示：

- 列表视图
- 卡片视图
- 回填任务台

### 8.2 尺寸

- 上下内边距：`9px`
- 左右内边距：`14px`
- 标题字号：`18px`
- 说明字号：`12px`
- 按钮保持紧凑高度

### 8.3 布局

- 桌面端保持单行。
- 说明文字空间不足时单行省略。
- 窄屏允许自然换行。
- 禁止通过增加上下空白解决内容拥挤。

## 9. 卡片页控制栏

### 9.1 左侧区域

- 放置现有排序按钮。
- 排序按钮改为粉色紧凑按钮。
- 当前排序项使用主粉色背景和白色文字。
- 非当前排序项使用浅粉背景、粉色边框和深粉文字。
- 排序操作继续在当前窗口执行。

### 9.2 右侧区域

排列顺序固定为：

1. `Events` 统计胶囊
2. `Current Page` 统计胶囊
3. 分页导航

### 9.3 统一尺寸

- 排序按钮、统计胶囊和分页按钮默认高度统一为 `30px`。
- 统计胶囊使用当前 `/sc-events` 的浅粉背景和深粉数值。
- 分页样式与 `/sc-events` 完全一致。
- 分页继续保留筛选、排序和每页数量参数。

## 10. 卡片网格

### 10.1 响应式列数

| 可用宽度 | 默认列数 |
|---|---:|
| 超宽屏 | 6 列 |
| 大屏 | 5 列 |
| 中屏 | 3 至 4 列 |
| 小屏 | 2 列 |
| 极窄屏 | 1 列 |

- 网格间距保持紧凑一致。
- 同一行卡片高度保持一致。
- 页面整体禁止横向滚动。

### 10.2 卡片外观

- 背景：白色到 `#fffafd` 的轻量渐变。
- 边框：`1px solid #eed5e1`。
- 圆角：`10px`。
- 阴影：低透明粉色阴影。
- 卡片内容区不得使用大面积深色背景。

### 10.3 卡片 hover

- 卡片上浮 `2px`。
- 边框增强为主粉色低透明边框。
- 阴影轻微增强。
- hover 不得改变卡片尺寸或网格位置。
- 动画时长控制在 `150ms` 至 `180ms`。

## 11. 封面区域

- 保持现有 2:3 封面比例。
- 保持当前图片来源、懒加载和解码设置。
- 禁止修改封面裁切逻辑和业务判断。
- 无封面状态使用浅粉背景、主粉色装饰和深粉文字。
- 封面上的数量或状态徽标使用粉色体系，避免使用无业务含义的多种高饱和颜色。

## 12. 卡片信息层级

卡片内容建议按以下顺序排列：

1. 日期与时间
2. Come Movie
3. 总片数与 SC 片数
4. Cooldown
5. 种类
6. 演员
7. Vessel
8. FG

### 12.1 时间

- 日期使用主文字色和粗体。
- 小时使用次要文字色和较小字号。
- 日期与时间保持同一行。

### 12.2 Come Movie

- 作为卡片主要链接展示。
- 使用深粉色、较高字重。
- 长内容单行省略。

### 12.3 数字信息

- 总片数、SC 片数、Cooldown 等数字使用 `tabular-nums`。
- 数字标签保持紧凑，禁止使用大尺寸统计卡占用卡片高度。

### 12.4 元数据标签

- 种类、演员、Vessel 和 FG 使用浅粉标签或紧凑信息行。
- 标签边框使用主边框色。
- 标签文字使用主文字或深粉色。
- 长内容单行省略。
- 禁止因单条长内容拉高整张卡片。

## 13. 月份分组

月份分组使用当前列表页的三组浅粉色：

- 第一组：`#fff8fb`
- 第二组：`#fff1f6`
- 第三组：`#fcecf4`

卡片不使用整张高饱和背景。月份区分采用以下任一轻量方式：

- 卡片顶部细线
- 卡片左侧细线
- 卡片内容区极浅背景变化

月份切换卡片可使用 `4px` 主粉色强调线。

## 14. 链接行为

### 14.1 新窗口打开

以下入口必须在新窗口打开：

- 事件详情
- Movie 详情
- Cast 详情
- 列表视图
- 卡片视图
- 回填任务台
- 其他进入不同页面的入口

统一设置：

```html
target="_blank"
rel="noopener noreferrer"
```

### 14.2 当前窗口操作

以下操作继续在当前窗口执行：

- 排序
- 分页
- 筛选
- 清空
- 卡片页内部状态切换

## 15. 空状态

- 空状态放在卡片网格区域内。
- 使用浅粉背景、虚线粉色边框和次要文字。
- 只显示必要提示，不增加重复统计或大面积插画。
- 空状态不得改变顶部和控制栏结构。

## 16. 动画

- 页面整体淡入：`280ms`。
- 顶部区域淡入上浮：`420ms`。
- 控制栏允许轻量延迟进入。
- 卡片允许小幅顺序淡入，但不得产生明显等待。
- hover 动画控制在 `150ms` 至 `180ms`。
- 必须提供 `prefers-reduced-motion: reduce` 覆盖。

## 17. 实施步骤

### 第一步：建立公共主题作用域

- 给列表页和卡片页增加 `next02-sc-pink-theme`。
- 将粉色主题变量和公共顶部样式收敛到共同作用域。
- 确认列表页表格规则仍只受 `next02-sc-events-rewrite` 控制。

### 第二步：重写卡片页顶部

- 将旧标题区替换为与 `/sc-events` 一致的紧凑顶部结构。
- 保留列表/卡片视图和回填入口。
- 补齐新窗口属性。

### 第三步：重写控制栏

- 排序放左侧。
- 统计胶囊和分页放右侧。
- 统一控件高度和粉色状态。

### 第四步：重写卡片外观

- 调整卡片边框、圆角、背景、阴影和 hover。
- 保持封面比例和现有数据绑定。
- 重排卡片信息层级。

### 第五步：补齐响应式与动画

- 按断点调整卡片列数。
- 检查控制栏换行。
- 增加 reduced-motion 覆盖。

### 第六步：静态与构建检查

- 检查新窗口属性。
- 检查字段和参数未变。
- 执行 `git diff --check`。
- 执行 `npm run build`。

## 18. 默认禁止项

- 禁止新增重复统计模块。
- 禁止增加无需求的大面积留白。
- 禁止改变封面尺寸和裁切逻辑。
- 禁止删除现有字段。
- 禁止更改 API、排序参数、分页参数和链接语义。
- 禁止让卡片页样式影响 `/sc-events` 列表页和详情页。
- 禁止修改其他 next 版本。
- 禁止用旧蓝紫主题覆盖当前粉色主题。

## 19. 验收标准

- 卡片页与列表页使用同一粉色主题。
- 顶部区域高度、文字层级和按钮密度与 `/sc-events` 一致。
- 排序位于控制栏左侧。
- `Events`、`Current Page` 位于分页左侧。
- 分页保持最右侧。
- 卡片字段完整且顺序清晰。
- 日期与时间保持同一行。
- 长文本不会拉高卡片。
- 同一行卡片高度一致。
- 页面入口全部在新窗口打开，并同时包含安全属性。
- 排序、分页和筛选继续在当前窗口执行。
- 页面整体无横向滚动。
- `git diff --check` 通过。
- `npm run build` 通过。
