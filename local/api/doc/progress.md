# API 优化进度

## 1. 记录规则

本文档记录 [后端 API 优化总方案](./plan.md) 的实际执行状态。状态只依据当前代码、命令结果、真实接口、真实数据库和可重复基准。

状态定义：

| 状态 | 含义 |
| --- | --- |
| 未开始 | 尚未执行代码修改或验证 |
| 盘点完成 | 已完成静态检查，尚无运行基线 |
| 基线完成 | 已取得可重复的优化前数据 |
| 进行中 | 已开始实施，尚未完成全部验证 |
| 待验证 | 代码已落地，缺少真实数据或完整回归 |
| 已完成 | 前后指标、正确性和回归全部通过 |
| 已回退 | 实施结果不满足要求，代码已撤销并记录原因 |
| 阻塞 | 外部条件缺失，已明确未验证范围 |

代码存在、测试通过或构建成功只能证明基础正确性，不能单独将性能任务标记为完成。
